# Django Shop

## Описание проекта
Интернет-магазин, разрабатываемый на Django в рамках учебного курса. 
Проект включает каталог товаров, систему авторизации, корзину покупок и оформление заказов.

## Технологии
- Python 3.10+
- Django 4.2+
- Bootstrap 5
- SQLite (в разработке)

## Функциональность
- Каталог товаров с категориями и фильтрацией
- Карточки товаров с детальной информацией
- Корзина покупок
- Оформление заказов
- Личный кабинет пользователя
- Административная панель для управления товарами

## Установка и запуск

1. Клонировать репозиторий:
```
git clone <url-репозитория>
cd django_shop
```

2. Создать и активировать виртуальное окружение:
```
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows
```

3. Установить зависимости:
```
pip install -r requirements.txt
```

4. Выполнить миграции:
```
python manage.py migrate
```

5. Запустить сервер разработки:
```
python manage.py runserver
```

6. Открыть в браузере:
```
http://127.0.0.1:8000/
```

## Структура проекта
- `catalog/` - приложение каталога товаров
- `config/` - настройки проекта
- `templates/` - HTML-шаблоны
  - `base.html` - базовый шаблон
  - `catalog/` - шаблоны приложения catalog
    - `home.html` - главная страница
    - `contacts.html` - страница контактов

- Ветка `develop` - текущая разработка
- Для каждой задачи создается отдельная ветка `feature/имя-задачи`
- Изменения вносятся через pull request в ветку `develop`
